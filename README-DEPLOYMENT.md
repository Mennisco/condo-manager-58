# Deploying Condo Manager 58 to Google Cloud Run

This guide walks you through deploying your React app to Google Cloud Run.

## Prerequisites

1. **Google Cloud Account** - Sign up at https://console.cloud.google.com (free tier available)
2. **Google Cloud CLI** - Download from https://cloud.google.com/sdk/docs/install
3. **Docker** - Download from https://www.docker.com/products/docker-desktop (for local testing)
4. **GitHub Repository** - Already done ✓

## Step 1: Set Up Google Cloud Project

### 1a. Create a new project
- Go to https://console.cloud.google.com
- Click the project dropdown (top left)
- Click "NEW PROJECT"
- Name it: `condo-manager-58`
- Click "CREATE"

### 1b. Enable required APIs
In the Cloud Console:
1. Go to **APIs & Services** > **Library**
2. Search for and enable:
   - **Cloud Run API**
   - **Cloud Build API**
   - **Container Registry API** (or Artifact Registry API)

### 1c. Set up billing (even though you'll likely stay in free tier)
- Go to **Billing** and link a payment method
- Cloud Run free tier: 180,000 vCPU-seconds and 360,000 GB-seconds per month
- For a low-traffic HOA app, you'll stay well within free tier

## Step 2: Configure Environment Variables

Before deploying, you need to set your app's environment variables (secrets) in Cloud Run.

### Identify your secrets:
1. Log into Emergent.sh
2. Go to your Condo Manager 58 app
3. Click **Redeploy** > **Secrets** tab
4. **Copy each secret name and value**
   - Example: `REACT_APP_API_BASE_URL`, `REACT_APP_MONGO_URI`, etc.

### Add them to Google Cloud Run:
You'll do this during deployment (Step 3c below).

## Step 3: Deploy to Cloud Run

### Option A: Using Cloud Console (Easiest - No CLI needed)

1. Go to https://console.cloud.google.com
2. In the left sidebar, click **Cloud Run**
3. Click **CREATE SERVICE**
4. Select **Deploy one revision from an existing image**
5. For **Container image URL**:
   - You need to build and push to Container Registry first
   - For now, skip to Option B or C

### Option B: Using Cloud Console with GitHub Integration (Recommended)

1. Go to **Cloud Run** in the Console
2. Click **CREATE SERVICE**
3. Select **Continuously deploy from a Git repository**
4. Click **SET UP WITH CLOUD BUILD**
5. Authorize Google Cloud to access your GitHub account
6. Select your repository: `Mennisco/condo-manager-58`
7. Select branch: `main`
8. Select **Dockerfile** as the build type
9. Under **Runtime settings**:
   - **Memory**: 512 MB (sufficient for React app)
   - **CPU**: 1 (default)
   - **Timeout**: 300 seconds
   - **Concurrency**: 80
10. Click **CREATE VARIABLES AND SECRETS**
11. Add your environment variables:
    - Click **Add Variable** for each non-sensitive setting
    - Click **Add Secret** for API keys and sensitive data
    - Example variables:
      ```
      REACT_APP_API_BASE_URL = https://your-api.emergent.host
      REACT_APP_MONGO_URI = [from your Emergent secrets]
      ```
12. Click **DEPLOY**

**The deployment will take 3-5 minutes. You'll see a URL like:**
```
https://condo-manager-58-xxxxx-uc.a.run.app
```

### Option C: Using gcloud CLI (If you prefer command line)

```bash
# Install and initialize gcloud
gcloud auth login
gcloud config set project condo-manager-58

# Build the Docker image and push to Cloud Run
gcloud run deploy condo-manager-58 \
  --source . \
  --platform managed \
  --region us-central1 \
  --allow-unauthenticated \
  --set-env-vars REACT_APP_API_BASE_URL=https://your-api.emergent.host
```

## Step 4: Test Your Deployment

1. Click the service URL generated by Cloud Run
2. Your app should load in the browser
3. Test key features:
   - Can you see the homeowner list?
   - Can you make API calls to your backend?
   - Are there any console errors? (Open Developer Tools: F12)

## Step 5: Set Up Automatic Redeployment (Optional but Recommended)

If you want the app to automatically redeploy when you push to GitHub:

1. In Cloud Run service details, click **EDIT & DEPLOY NEW REVISION**
2. Under **Build settings**, ensure it's connected to your GitHub repo
3. Enable automatic rebuilds on push

## Troubleshooting

### App shows 404 or blank page
- Check Cloud Run logs: **Cloud Run** > Your service > **LOGS** tab
- Verify `react-scripts` build works locally: `cd frontend && yarn build`

### API calls failing / CORS errors
- Make sure your backend (Emergent API) allows requests from your Cloud Run domain
- Add `https://condo-manager-58-xxxxx-uc.a.run.app` to CORS whitelist

### Secrets not working
- Verify variable names match what your React app expects (with `REACT_APP_` prefix)
- Restart the Cloud Run service

### Still seeing Emergent domain
- Clear browser cache (Ctrl+Shift+Delete)
- Try incognito/private window
